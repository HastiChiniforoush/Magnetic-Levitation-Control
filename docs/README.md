
# Technical Documentation

This directory contains the technical documentation for
the Magnetic Levitation Control project, completed as
part of the Microelectronic Control Systems laboratory
at Rhine-Waal University of Applied Sciences in 2025.

## Documents

### 1. Controller Comparison

[Controller-Comparison.md](Controller-Comparison.md)

A technical comparison of the P, PD, and PID controllers,
including:

- Controller parameters and experimental tuning
- Hall-effect sensor feedback and PWM control
- Stability, oscillations, and disturbance response
- Integral limiting and derivative noise handling
- Experimental results and engineering observations

### 2. Technical Laboratory Report

The technical report documents the experimental setup,
controller implementation, calibration procedures,
testing methodology, and conclusions.

The report will be added as a separate PDF.

## Project Scope

The control algorithms were implemented in C and tested
using university laboratory hardware.

The supporting hardware drivers and initial firmware
framework were provided by the university. The controller
logic, parameter tuning, and experimental evaluation
were completed during the laboratory exercises.
